Secure Message Application
This Java application demonstrates basic cryptography and information security concepts. The user enters a message, and the program creates a SHA-256 hash to verify its integrity. The message is then encrypted using AES with a randomly generated key and decrypted back to its original form. After decryption, the program creates another SHA-256 hash and compares it to the original hash. If the hashes match, the program displays that the message's integrity has been verified. AES demonstrates confidentiality by preventing the encrypted message from being easily read without the key, while SHA-256 demonstrates integrity by detecting changes to the message. The application also demonstrates availability because the user can run the program when needed to process a message. Random key generation is important because unpredictable keys make cryptographic systems more difficult to attack. This project is intended as an educational demonstration of encryption, hashing, randomness, and the CIA triad.
